# WAROX Component Model

## Source dataset or system

WAROX records geological field observations and samples collected by GSWA. It includes rock descriptions, structural
measurements, field photographs and links to related geoscience information.

GSWA’s
[WAROX data compilation](https://warmelpdstageodocspub.blob.core.windows.net/direct-links/4fc69b2e-853c-4715-b45a-580ec04b5895.pdf)
describes the dataset and how field sites can be used to find related observations. The
[Data and Software Centre](https://dasc.dmirs.wa.gov.au/home?productAlias=WAROX+Lithology) provides WAROX lithology data.
