# ENS Component Model

## Source dataset or system

The Explanatory Notes System (ENS) describes Western Australian rock units and relates them to tectonic units and
geological events.

GeoVIEW.WA can generate reports for a single unit or event, or for a group selected by criteria such as location, name or
age. See the
[WA Government ENS guide](https://www.wa.gov.au/service/natural-resources/mineral-resources/access-explanatory-notes-system-ens).
