# MINEDEX Component Model

## Source dataset or system

MINEDEX records Western Australian mines, mineral deposits, prospects and projects. Records can describe site geology,
commodities, operating status, ownership, resource estimates and production.

The
[WA Government MINEDEX guide](https://www.wa.gov.au/service/natural-resources/mineral-resources/access-mines-and-mineral-deposits-minedex)
describes text and spatial searches, reports and downloads.
