# CIMS Component Model

## Source dataset or system

GSWA’s Core Information Management System (CIMS) supports the management of drill core and other samples held by its core
libraries.

The
[GSWA Annual Review 2018–19](https://warmelpdstageodocspub.blob.core.windows.net/gswa-publications/b9d38627-e7a7-4f1f-ad93-6294f0ba6177.pdf)
identifies CIMS as a core library system. Public information about the Perth and Kalgoorlie holdings is available through
[WAPIMS](https://wapims.dmp.wa.gov.au/wapims/).
