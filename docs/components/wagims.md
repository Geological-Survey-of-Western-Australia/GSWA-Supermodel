# WAGIMS Component Model

## Source dataset or system

The [GSWA Geoscience Strategy](https://www.dmp.wa.gov.au/Documents/Geological-Survey/Geoscience_Strategy_May_2022.pdf)
identifies WAGIMS and GIMENS as part of its work on geochronological, isotopic and metamorphic data.

The [GSWA program review](https://storymaps.arcgis.com/stories/d75d15410889424c9d1ae8a98ff0ba7c) describes GIMENS as the
module for compiling and publishing geochronology records from data held in WAGIMS.
