# MAGIX Component Model

## Source dataset or system

MAGIX registers geophysical surveys and provides access to survey datasets. It covers airborne surveys commissioned by
industry and regional airborne and ground surveys commissioned by government.

The [WA Government MAGIX guide](https://www.wa.gov.au/service/natural-resources/mineral-resources/access-magix-online)
describes how to search and obtain survey data through MAGIX, GeoVIEW.WA and the Data and Software Centre.
