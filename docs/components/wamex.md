# WAMEX Component Model

## Source dataset or system

WAMEX provides access to public mineral exploration reports submitted by companies in Western Australia. Reports describe
exploration activities and results, including drilling, sampling and assaying.

The
[WA Government WAMEX guide](https://www.wa.gov.au/service/natural-resources/mineral-resources/access-mineral-exploration-reports-wamex)
describes how to search for reports. For structured drillhole and surface sample data extracted from reports, see
[DRILLHOLES](drillholes.md).
