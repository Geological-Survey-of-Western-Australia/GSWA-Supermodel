# WAPIMS Component Model

## Source dataset or system

The Western Australian Petroleum and Geothermal Information Management System (WAPIMS) provides public information from
energy resource exploration and production. It includes records about titles, wells, geophysical surveys and samples held
in the core libraries.

The
[WA Government WAPIMS guide](https://www.wa.gov.au/service/natural-resources/energy-resources/access-petroleum-and-geothermal-exploration-information-wapims)
provides access to the system and related information.
