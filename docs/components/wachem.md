# WACHEM Component Model

## Source dataset or system

WACHEM compiles geochemical analyses of rocks, regolith and drill core collected by GSWA. Results include major element
oxides, trace elements and isotopes.

The [GSWA Geochemistry dataset](https://catalogue.data.wa.gov.au/dataset/gswa-geochemistry) describes analytical methods,
units, detection limits and quality control data, and provides downloads.
